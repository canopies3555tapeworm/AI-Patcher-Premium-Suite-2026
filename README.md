## FAQ

### Is OmniPatch safe to use on my computer?

OmniPatch is designed to be safe and does not contain malicious code. However, as with any software that modifies system files, it may trigger false positives in anticomponent software. We recommend adding it to your security software's whitelist.

### Which AI applications does OmniPatch currently support?

OmniPatch currently supports ChatGPT (Plus/Enterprise), Claude (Pro/Team), Microsoft Copilot Pro, GitHub Copilot, Cursor AI, Devin, and JetBrains AI Assistant. Support for new applications is added regularly.

### How often are updates provided for OmniPatch?

We release updates as soon as new versions of supported AI applications are launched or when patches become outdated. Major updates are typically deployed within 48 hours of a target application's update.

### Will using OmniPatch violate the terms of service of these AI platforms?

OmniPatch modifies the local application files to alter feature checks. While this compatibility client-side restrictions, users should be aware that it may violate the terms of service of the respective platforms.

### Do I need an internet connection to use the patcher?

Yes, an internet connection is required during the patching process to download the latest activation modules. The patched applications themselves will function offline if they normally support it.

### Can OmniPatch be used on macOS or Linux?

Currently, OmniPatch is a Windows-only desktop application. There are no official plans for macOS or Linux versions at this time.

### What happens if a patched application receives an official update?

Official updates will often overwrite the patch, requiring you to run OmniPatch again. We recommend disabling auto-updates for the patched applications until our tool is updated.

### Is there a way to revert the changes made by OmniPatch?

Yes, OmniPatch creates a backup of the original application files before patching. You can use the 'Restore Original' feature within the tool to revert any changes.

### Does OmniPatch work with the free tiers of these AI applications?

No, OmniPatch is designed to unlock and activate premium or paid features. It requires that the target application is installed but does not activate features for applications that don't have a premium tier.
